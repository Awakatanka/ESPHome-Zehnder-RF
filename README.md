# ESPHome-Zehnder-RF

HARWARE:  
Zehnder ComfoFan Silent (Randaarde) https://www.zehnder.nl/nl/ventilatie/mechanische-ventilatie/comfofan-silent  
Zehnder RFZ zender  https://www.zehnder.nl/nl/ventilatie/bedieningen-sensoren-connectiviteit/zehnder-rfz/cu-rf-z1-rfz-zender-rfz-zender-stand-1-2-3-en-timerfunctie-incl-batterij-cr2032  
Zehnder CO2 Sensor 0-10V  https://www.zehnder.nl/nl/ventilatie/co2-gestuurde-ventilatie/zehnder-co2-room-sensor-0-10v  

SOFTWARE:  
Hassio core 2026.2.3  
ESPhome 2026.2.1   

If the Zehnder doesn't respond: Unplug the Zehnder unit for 10 seconds.  
Once power is restored, restart the ESP. The Zehnder will then be open for new handshakes for 60 seconds.
